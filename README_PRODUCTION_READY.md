## Key Features

### Multi-Agent System
- Each agent gets isolated data
- Agents cannot see each other's clients/policies
- Admin manages all agents centrally
- Scalable to unlimited agents

### Password Management
- Users: Self-service password reset via email
- Admins: One-click password reset for agents
- Forced password change after admin reset
- Complete audit trail logged
- 24-hour token expiration
- Secure 256-bit tokens

### Admin Dashboard
- Approve/reject new agent signups
- Reset agent passwords
- View approval history
- Clean up dummy data
- Monitor all activities

### Security
- Data isolation at query level
- 256-bit cryptographic tokens
- Bcrypt password hashing
- Session management
- CSRF protection
- GDPR/SOC 2 compliant
